            SCORING RULES

            Hit (1.0): a specific dated depiction matched by a specific real event. Partial (0.5): right theme, wrong specifics, or a match plausibly driven by coincidence. Expired (0): an in-show date passed.

            Pending stays out of the denominator until resolved. Myths and fiction never enter it.

            MEDIA & SOURCING POLICY

            Photographs are real. Each file resolves a live image from the Wikipedia article of the real-world counterpart, with photographer/licence credit from Wikimedia. Click any photo for the full-size version and its file page.

            No broadcast footage. Simpsons clips are copyrighted; this site embeds none and hosts none. Scene reconstruction animations were removed. Instead each file links to the episode guide and a scoped clip search.

            Timecodes removed. Precise in-episode timestamps vary by cut, region and platform and could not be verified, so invented timecodes were deleted rather than presented as fact.

            PROFILES & PRIVACY

            Profiles are local to this browser. Passwords are salted (16 random bytes) and hashed with 30,000 rounds of SHA-256; only the hash is stored. Five failed attempts trigger a 30-second cooldown.

            Stars, notes, forecasts, saved views, XP, badges and run history are namespaced per profile. Guest data is kept separately. Nothing is transmitted; there is no server.

            Because there is no server, a forgotten password cannot be recovered — the profile can only be reset, which erases its data. Guest mode always works.
